# Banking website concepts

Public collection of banking landing-page prototypes. Each project is independent.

| Project | Source | Live site |
|---|---|---|
| P1tch | [projects/p1tch](projects/p1tch/) | [p1tch.vercel.app](https://p1tch.vercel.app) |
| Landing page | [projects/landing-page](projects/landing-page/) | [Vercel site](https://landing-page-gamma-six-48.vercel.app) |

Serve each folder as a static website. Vercel deployments use the corresponding folder as Root Directory, framework Other, no build command, and output directory `.`.

These are design prototypes, not banking services. Existing sample links and external assets are retained from the source projects; migration does not establish that those services work.

Main-branch Git histories are preserved. The original repositories and GitHub Pages sites remain available during migration. The repositories `sbi-recreation`, `bank-landing-page` and `bank-landing-page-designcode` could not be imported because GitHub blocked access; they are not included here.

Private portfolio sources live in [asheshg/projects](https://github.com/asheshg/projects). Agent skills remain in [asheshg/skills](https://github.com/asheshg/skills).
